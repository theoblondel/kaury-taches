# Journal des versions

## 1.0.0 — 26 septembre 2026

Première version publique.

- Sections Quotidien, Aujourd'hui, Demain, Plus tard, À faire et Fait.
- Les quotidiennes se décochent seules chaque jour ; la section se replie quand tout est fait.
- Une tâche prévue pour demain passe dans Aujourd'hui le lendemain, et y reste marquée « Prévu hier » si elle n'est pas faite.
- Glisser-déposer entre sections et dans l'ordre (appui long).
- « + Ajouter » dans chaque section, avec saisie en rafale.
- Fiche d'une tâche : renommer, déplacer, dater, remonter en tête, supprimer.
- Annuler pendant 4 secondes après chaque action importante.
- Widget petit, moyen (deux colonnes), grand, et trois formats pour l'écran verrouillé.
- Thèmes clair et sombre, polices Kaury mises en cache pour fonctionner hors ligne.
- Données dans un fichier JSON lisible, dans iCloud Drive.
